# Research outputs

This directory contains local CSP runs used to validate database completeness
and structural/powder-pattern matching.

Small, curated inputs and CSV summaries may be versioned. Reproducible binary
databases, SQLite sidecars, archives, logs, status files and restart caches are
ignored by Git; keep those in backed-up research storage when transferring runs
between a workstation, Aloe and Neon.

Each committed result set should include the command, mol-CSPy revision,
Critic2 version/feature line, PXRD backend and relevant clustering thresholds in
its accompanying report or job script.
